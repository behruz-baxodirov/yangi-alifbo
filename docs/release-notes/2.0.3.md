**2.0.3 — yangi versiya çiqsa, dastur özi aytadi.**

Endi yangilanişni saytdan qidirişingiz şart emas. Yangi versiya çiqsa, menyu-barda **ö↑** körinadi va ekranda bir marta xabar çiqadi. **ö** ustida öng tugma → **Yangi versiya bor — yangilaş…** ni bossangiz, Terminal oçiladi va örnatiş buyruği körinib turgan holda işga tuşadi. Heç narsa yaşirin örnatilmaydi.

Buning uçun dastur kuniga köpi bilan bir marta GitHubʼdan oxirgi versiya raqamini söraydi: GitHub faqat IP manzilingiz va dastur versiyasini köradi, yozgan matningiz ham, sozlamalaringiz ham yuborilmaydi. Istamasangiz, menyudagi **Yangilanişni özi tekşirsin** belgisini olib taşlang: dastur internetga umuman çiqmaydi.

Adaşgan harfni öçirganda ham töğri çiqadi: **c**, **b**, ⌫, **h** → **ç**. Kursorni orqaga surib örtadagi harfni öçirsangiz ham (**cbh** dagi **b**), qolgan harflar birikadi: **ç**, **ş**, **ö**, **ğ**. Bu kursor atrofini körsatadigan ilovalarda işlaydi (masalan Claude, Notes); körsatmaydiganlarida oldingidek qoladi.

Bu versiyaga ötiş uçun oxirgi marta qöl bilan yangilang (Terminal):
```
curl -fsSL https://yozgich.uz/install.sh | bash
```

Yangilangandan keyin macOS Accessibility ruxsatini qayta söraşi mumkin: *Open System Settings* → Privacy & Security → **Accessibility** → **Yangi alifbo** ni yoqing (eski yozuv bölsa, uni öçirib qayta qöşing).

Windows: `YangiAlifbo-windows-beta.exe` — beta, özgarmagan.
