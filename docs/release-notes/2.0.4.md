# Yangi alifbo 2.0.4

- Yangi versiya belgisi `ö↑` / `A↑` ustidagi çap bosiş yangilaş menyusini oçadi.
- Oldin topilgan, lekin körsatilmagan yangilaniş xabari dastur qayta oçilganda ham çiqadi;
  bir versiya haqidagi xabar bir marta körsatiladi.
- Yangilaş buyruği aniq Terminal ilovasida oçiladi.
- Option bilan yozilgan `‘` va `’` apostroflari harf ögiriş mantiqiga yetib boradi;
  Command va Control yorliqlari odatdagidek işlaydi.
- Ruxsat menyusidagi tutuq belgisi yangi alifboga moslandi.

Mac ilovasi nomi Accessibility röyxatida **Yangi alifbo** bölib qoladi.
Yangilaşdan keyin macOS Accessibility ruxsatini qayta söraşi mumkin.

Örnatiş / yangilaş:

```bash
curl -fsSL https://yozgich.uz/install.sh | bash
```

Windows beta kodi şu relizda özgarmaydi; Windows fayli oldingi v2.0.3 relizidan olinadi.
Relizga ikkala fayl qöşilişi şart:

- `YangiAlifbo.zip`
- `YangiAlifbo-windows-beta.exe`

Naşrdan oldingi tekşiruv: Swift testlari, universal arm64/x86_64 yiğiş,
plist va ad-hoc imzo tekşiruvi. Haqiqiy Chrome/Terminal/HUD qöl sinovlari
avtomatik test bilan teng deb hisoblanmaydi.
