# Redesign stage 1: ground, header, script switcher, footer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dotted amber ground with a flour ground and an amber top band, and rebuild the shared header (one script switcher, compact phone menu) and footer (dark, four aligned columns) on every page in all four versions.

**Architecture:** Shell-only change. `web/styles.css` gets the new ground and band (band drawn with `::before` on `.bar` and `.hero`, no markup moves, so the IDs `web/app.js` binds stay put). Header and footer partials (`site/partials/`, `site/ru/partials/`) get new markup; `site/build.mjs` fills two new placeholders (script mark, section `aria-current`). `web/sahifa.js` drives the two `<details>` menus; they work without JS.

**Tech Stack:** Static HTML/CSS/vanilla JS ES modules, Node ≥ 22 generator and `node --test`, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-25-fon-header-footer-design.md` — read it before every task; copy, colours, sizes and breakpoints come from it verbatim. Approved mockup: https://claude.ai/artifact/PYVRoRErUgynBsWBnZoN2S (boards «E — B va D birga» and «Header, til tanlaş, telefon menyusi»).

## Global Constraints

- Sources in `site/pages/**`, `site/partials/**` are in the new alphabet (ö ğ ş ç, tutuq ʼ U+02BC); `/eski/` and `/kr/` are generated by converting text nodes; Russian lives only in `site/ru/**`. Anything inside an element with `data-lotin` or inside `⟦…⟧` is not converted.
- Language surface, read from code: four versions from `TILLAR` in `site/build.mjs` (`yangi` "", `eski` `eski/`, `kr` `kr/`, `ru` `ru/`); header/footer per version come from `site/partials/*` (yangi, eski, kr) and `site/ru/partials/*` (ru); the switcher's links use `{{href:<til>}}{{current:<til>}}`; `web/sahifa.js` keeps `?n=` and `#…` via `placeIn()`.
- Never hand-edit `web/**/index.html`. Run `npm run build` before every commit touching `site/` or `web/styles.css`/`web/*.js`, commit the generated `web/` too. Bump `ASSET_V` in `site/build.mjs` (now `"27"`) once per task that changes CSS or JS.
- DESIGN rules that stay: 3px corners, no shadows, no Doto line ending in ".", no ğ in Doto, Cyrillic/Russian headings fall back to Onest 800 (`web/styles.css:98` list), clay only on flour/dough.
- New token `--flour-deep: #f4e8d2`. Footer ground `--char`, text `--slab-ink`, headings `--flour`, accent `--crust`.
- Breakpoints: header nav ↔ menu button at 1024px (`max-width: 1023px`); switcher label hidden below 640px.
- Copy (exact): «Yuklab oliş», «Kompyuterga yuklab oliş», «Menyu», «Menyuni yopiş», «Sayt yozuvi», «Bölimlar», «Yana», «Asosçi», «Aloqa uçun yozing», «Bepul,<br>hamma uçun», «Qöllab-quvvatlaş», «Davlat loyihasi emas», «© 2026 Yozgiç». Switcher rows per spec §4.3 table. Russian: «Скачать», «Скачать на компьютер», «Меню», «Закрыть меню», «Разделы», «Ещё», «Основатель», «Написать», «Бесплатно,<br>для всех», «Поддержать», «Не государственный проект».
- Tests use plain commands: `node --test site/build.test.mjs`, `node --test web/test/qobiq.test.mjs`; full suite `npm test`.
- Shared machine: preview with `preview_start {name: "web-8767"}`; never stop servers you did not start.
- Push rule (`push-deploy-without-asking`): after Task 4 passes, `git fetch`, rebase this branch on `origin/main`, re-run `npm test`, fast-forward `main`, push; check the live site after Pages deploys.

## Review Focus

1. **`/kr/` and `/eski/` pages:** switcher names and hints stay as written (Latin «Yangi alifbo», «o' g' sh ch»), while the screen-reader label «Sayt yozuvi» and menu labels are converted like other text. → Task 2 test `kr switcher keeps names, converts labels`.
2. **No JavaScript:** both menus open and close natively and every switcher link navigates. → Task 2 test asserts `<details class="til">`/`<details class="site-menu">` with `<summary>` and real `href`s; Task 4 browser check with JS disabled.
3. **320–375px phones and 200% text:** header stays one row (logo, switcher, menu button) with no horizontal page scroll; the full-bleed band must not create one (Windows desktop scrollbars too). → `body { overflow-x: clip }`; Task 4 measures `scrollWidth <= innerWidth` at 320, 375, 1280.
4. **Both menus at once, Escape, outside click:** opening one closes the other; Escape closes and returns focus to its summary; a click outside closes. → Task 2 `sahifa.js`; Task 4 keyboard check.
5. **Home band continuity:** no flour gap between `.bar` and `.hero` on the home page, and inner pages show the band only behind the header. → Task 1 visual check at 375 and 1280.
