Телефонда ёзиш

Телефонга ҳеч нарса ўрнатмайсиз: бор клавиатурага битта тил қўшасиз ёки ҳарфни босиб туриб танлайсиз. Ўзингизга қулай усулни очинг.

1Озарбайжонча клавиатура Тавсияö ğ ş ç алоҳида тугмада туради. Бир марта, икки дақиқада қўшасиз.

ö ğ ş ç алоҳида тугмада туради, босиб туриш шарт эмас. Бир марта қўшасиз, кейин 🌐 тугмаси билан алмаштирасиз.

  1. 1

    Созламаларни очинг

    Settings → General → Keyboard. Рушча: Настройки → Основные → Клавиатура.

  2. 2

    Янги клавиатура қўшинг

    Keyboards → Add New Keyboard… Рушча: Клавиатуры → Новые клавиатуры.

  3. 3

    Озарбайжончани танланг

    Рўйхатдан Azerbaijani (Азербайджанская) ни босинг.

  4. 4

    Ёзаётганда алмаштиринг

    🌐 тугмасини босинг: экранда Azərbaycan клавиатураси чиқади.

    Бу клавиатурада автоматик тузатиш йўқ, шунинг учун ўзбекча сўзларингизни “тўғрилаб” бузмайди.

Катта I учун ı тугмаси

Бу клавиатурада иккита i бор: i ва ı (нуқтасиз). Катта ҳарфда i тугмаси İ (нуқтали) беради, у ўзбекчада йўқ.

  • iiкичик i
  • ⇧ ıIкатта I
  • ⇧ iİкерак эмас

2Ҳарфни босиб туришҲеч нарса қўшмасдан: o, g, s, c ни босиб туриб, менюдан тўғри ҳарфни танлайсиз.

Ҳарфни босиб туринг, меню очилади. Бармоқни тўғри ҳарфга суриб қўйиб юборинг.

ğ: тепасида қайиқча, нуқта эмас

ş: остида илмоқ. ș (вергул) бошқа ҳарф

ç: остида илмоқ

ğ ва ş iOS 17 ва янгисида бор. Менюда йўқ бўлса, iOSʼни янгиланг ёки конвертердан фойдаланинг. Тутуқ ʼ учун оддий ' ёзинг, конвертер уни тўғрилайди.

3КонвертерОдатдагидек o', sh деб ёзасиз, кейин матнни бир босишда янги алифбога ўгирасиз.

Камдан-кам ёзсангиз қулай: матнни одатдагидек ёзиб, конвертерга жойланг. Ўгириш телефонингизнинг ўзида бажарилади.

Конвертерни очиш

1Озарбайжонча клавиатура ТавсияGboard учун қадамлар. ö ğ ş ç алоҳида тугмада туради.

Қуйидаги қадамлар Gboard учун. Озарбайжонча жойлашувни қўшиб, ö ğ ş ç ни ёзиб текширинг: жойлашув ва меню номлари клавиатура версиясига қараб фарқ қилиши мумкин.

  1. 1

    Gboard созламаларини очинг

    Клавиатура очиқ турганда ⚙ белгисини босинг. Ёки: Settings → System → Languages & input → On-screen keyboard → Gboard.

  2. 2

    Тил қўшинг

    Languages → Add keyboard. Рушча: Языки → Добавить клавиатуру.

  3. 3

    Озарбайжончани танланг

    Azərbaycan (Azerbaijani) ни ва жойлашувни танланг → Done (Готово).

  4. 4

    Ёзаётганда алмаштиринг

    🌐 тугмасини босинг ёки бошлиқ тугмасини босиб туринг.

    Samsungʼда: клавиатура созламалари → Languages and types → Manage input languages; рўйхатда бўлса, Azərbaycan ни қўшинг.
