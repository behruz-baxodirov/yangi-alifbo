Мақолалар

sʼh қоидаси: Isʼhoq, asʼhob, musʼhaf

2026-йил 24-октябр · Беҳруз Баходиров

Янги алифбода sh ҳарф бирикмаси ş бўлди. Лекин баъзи сўзларда s ва h битта товуш эмас, алоҳида ўқилади. Уларда sh ни ş га айлантириб бўлмайди: Isʼhoq исми Işoq бўлиб қоларди.

Қандай ёзилади

Бу сўзлар эски ёзувдагидек тутуқ билан ёзилади, фақат тутуқнинг шакли ʼ: Is'hoq → Isʼhoq, as'hob → asʼhob, mus'haf → musʼhaf.

Yozgiç ва конвертер нима қилади

Yozgiç клавиатураси ва конвертер s'h ни sʼh қилади, sh ни ş. Тутуқсиз ёзилган Ishoq, ashob, mushaf ни ҳам конвертер танийди ва Isʼhoq, asʼhob, musʼhaf қилиб ўгиради. Кириллдаги Исҳоқ ҳам Isʼhoq бўлади.

Бошқа сўзни текширмоқчи бўлсангиз, уни «Бу сўз қандай ёзилади?» майдонига ёзинг.

Расмий имло қоидалари ҳали эълон қилинмаган. Мақола ЎРҚ-1184-сон Қонун ва Yozgiç қоидаларига асосланган; Yozgiç давлат лойиҳаси эмас.
