    Саволлар

    Янги алифбода нима ўзгарди?

    Тўрт ҳарф янги белги олди: o' → ö, g' → ğ, sh → ş, ch → ç. Сўз ичидаги тутуқ ʼ белгиси билан ёзилади: маъно, эълон. ng ўзгармайди. Масалан, “o'zbek tili” энди “özbek tili” деб ёзилади.

    Янги алифбо қачон кучга киради?

    ЎРҚ-1184-сон Қонун 2026-йил 21-октябрда имзоланган ва 2027-йил 22-апрелда кучга киради. Расмий имло қоидалари ҳали эълон қилинмаган. Yozgiç давлат лойиҳаси эмас: қоидалар Қонунга ва матбуотдаги хабарларга асосланган.

    Янги алифбо клавиатурасини қандай ўрнатаман?

    Macʼда Terminalʼга битта буйруқни жойланг, дастур ўзи юкланади ва ишга тушади. Windowsʼда beta файлни юклаб очинг. Иккаласи ҳам бепул. Қадамлар: юклаб олиш ва ўрнатиш.

    ö, ğ, ş, ç ҳарфларини қандай ёзаман?

    Компютерда Yozgiç клавиатурасини ўрнатинг: o' ёзсангиз ö, g' ёзсангиз ğ, sh ёзсангиз ş, ch ёзсангиз ç чиқади. Янги тугмаларни ёдлаш шарт эмас. Телефонда озарбайжонча клавиатурани қўшинг ёки ҳарфни босиб туринг: o → ö, g → ğ, s → ş, c → ç. Батафсил: Телефонда ёзиш.

    Кирилл ёки эски лотин матнини янги алифбога қандай ўгираман?

    Матнни конвертерга жойланг: кирилл (Янги алифбо) ҳам, эски лотин (o'zbek) ҳам янги алифбога (özbek) шу заҳоти ўгирилади. Матн ҳеч қаерга юборилмайди, ҳаммаси браузерингизда ишлайди.

    Клавиатура ёқилганини қандай биламан?

    Меню-барда (экраннинг юқори ўнг бурчагида) ö турган бўлса, ёқилган; A турган бўлса, ўчиқ. Алмаштириш: ⇧ Shift ни икки марта босинг ёки ö ни босинг. Бошқа тугма танлаш: ö устида ўнг тугма → “Ёқиш/ўчириш тугмаси”. ⌃ Control + Space ва fn энди фақат тилни алмаштиради.

    Windowsʼда соат ёнидаги иконка ҳолатни кўрсатади, Ctrl + Alt + Space ёқиб-ўчиради.

    Инглизча ёки код ёзаётганимда нима қиламан?

    Клавиатура ҳар қандай сўзда o' ва sh ни алмаштиради: shop.uz ҳам şop.uz бўлиб қолади. Инглизча ёзишдан олдин ⇧ Shift ни икки марта босиб ўчириб қўйинг (меню-барда A чиқади). Рус клавиатурасида ёзганингизга тегмайди. Windowsʼда: Ctrl + Alt + Space.

    Рухсат сўраяптими? Матнимни кўриб турадими?

    Ҳа, бир марта: Accessibility рухсати (тугмаларни кўриб, o' ни ö га алмаштириш учун). Русча macOSʼда: “Конфиденциальность и безопасность → Универсальный доступ”. Матн ҳеч қаерга юборилмайди. Дастур кунига кўпи билан бир марта GitHubʼдан янги версия рақамини текширади: GitHub фақат IP манзилингиз ва дастур версиясини кўради, матн ҳам, созламалар ҳам юборилмайди. Менюдаги “Янгиланишни ўзи текширсин” белгисини олиб ташласангиз, интернетга умуман чиқмайди.

    Янгилангандан кейин macOS рухсатни қайта сўраши мумкин, чунки дастур Apple сертификати билан имзоланмаган (лойиҳа бепул). Конвертер ҳам фақат браузерингизда ишлайди.

    Macʼдан қандай ўчираман?

    Terminalʼда: curl -fsSL https://yozgich.uz/uninstall.sh | bash

    GitHubʼдаги .zip файлни қўл билан очманг: илова Apple сертификатисиз, macOS уни “damaged” деб блоклайди. Ўрнатишнинг ягона тўғри йўли юқоридаги Terminal буйруғи.

    Ўчиргандан кейин System Settings → Privacy & Security → Accessibility рўйхатидан Yangi alifbo ни ҳам олиб ташлашингиз мумкин.

    Янги версияни қандай оламан?

    Сайт ва конвертер ўзи янгиланади: саҳифани очсангиз, энг янгиси чиқади. Mac клавиатурасини янгилаш учун Terminalʼга ўрнатиш буйруғини қайта жойланг: curl -fsSL https://yozgich.uz/install.sh | bash. Дастур эскисининг устидан янгиланади, кейин macOS Accessibility рухсатини бир марта қайта сўрайди.

    2.0.3 дан бошлаб Mac дастури янги версия чиққанини ўзи айтади: меню-барда ö↑ кўринади, ö устида ўнг тугма билан “Янги версия бор” ни боссангиз, Terminal очилиб шу буйруқ ўзи ишга тушади.

    Windowsʼда соат ёнидаги иконкадан “Чиқиш” ни танланг, янги YangiAlifbo-windows-beta.эхе файлни юклаб олинг ва очинг.

    Windowsʼда ишлайдими?

    Ҳа, beta версия: YangiAlifbo-windows-beta.эхе. Ёқиш ва ўчириш: Ctrl + Alt + Space. Автоматик тест Notepadʼда ўтган, лекин ҳақиқий компютерларда ҳали кам синалган; хато топсангиз GitHubʼда ёзинг.

    Ўчириш: соат ёнидаги иконкани ўнг тугма билан босиб “Чиқиш” ни танланг, кейин файлни ўчиринг. Автоматик ишга тушишга қўшган бўлсангиз, shell:startup папкасидаги ёрлиқни ҳам ўчиринг.

    Yozgiç бепулми? Қандай ёрдам берсам бўлади?

    Ҳа, клавиатура ҳам, конвертер ҳам бепул ва бепул қолади. Ёрдам бермоқчи бўлсангиз, Yozgiçni дўстларингизга улашинг ёки исталган миқдорда донат қилинг. Хато топсангиз, GitHubʼда ёзинг.

    Телефонда қандай ёзаман?

    Энг қулайи: телефонга озарбайжонча клавиатурани қўшинг, унда ö ğ ş ç алоҳида тугмада. Катта I учун Shift + ı ни босинг: i нинг катта ҳарфи İ (нуқтали), ўзбекчада эса I керак. Клавиатурани алмаштирмасдан ҳам бўлади: ҳарфни босиб туринг, o → ö, g → ğ, s → ş, c → ç (iPhoneʼда iOS 17 дан бошлаб). Турк клавиатураси сўзларни туркчага тузатиб юборади. Батафсил, расмлари билан: Телефонда ёзиш.
